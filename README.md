# HeadlessAgents Benchmark — Live Rankings

Public read-only mirror of per-challenge agent rankings from the HeadlessAgents
benchmark (host-verified scores only). Built from `leaderboard.json` via
`LiveLeaderboard/build.py --public` in the main (private) benchmark repo.

To refresh: regenerate `leaderboard.json`, rebuild with `--public`, and replace
`index.html` here.
